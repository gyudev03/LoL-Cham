# Chamlog

개인용 League of Legends 챔피언 숙련도 분석 웹앱입니다. 사용자가 선택한 챔피언의 공식 숙련도와 최근 솔로랭크·자유랭크 전적을 분석합니다.

## 실행

```powershell
npm install
Copy-Item .env.example .env
```

`.env`의 `RIOT_API_KEY`에 [Riot Developer Portal](https://developer.riotgames.com/)에서 발급한 키를 입력한 다음 실행합니다.

```powershell
npm run dev
```

- 웹 화면: `http://localhost:5173`
- API 서버: `http://localhost:8787`

`RIOT_API_KEY`는 서버만 읽습니다. 키를 `VITE_` 환경 변수로 만들거나 Git에 커밋하면 안 됩니다.

## 동기화 범위

저장된 사용자를 선택하면 해당 계정의 동기화가 자동으로 시작됩니다. 사용자는 **데이터 새로고침**으로도 언제든 다시 동기화할 수 있습니다.

- Riot ID와 태그를 통한 PUUID 조회
- KR 랭크 정보
- 공식 챔피언 숙련도
- 솔로랭크(420)와 자유랭크(440)의 이번 시즌 전체 매치 목록
- 이번 시즌 게임을 기반으로 한 챔피언별 개인 통계 및 AI 숙련도
- 최근 게임에서 가장 많이 사용한 룬 조합(Riot Data Dragon 정적 데이터로 명칭 변환)

AI 숙련도는 역할별 핵심 지표 50%, 최근 승률 20%, 최근 플레이 빈도 15%, 플레이 횟수 10%, 비교 기준 5%의 내부 가중치를 사용합니다. 메타 티어와 카운터는 외부 데이터 수집 규정을 검토한 뒤 별도로 연동합니다.

AI 숙련도는 이번 시즌 분석 게임이 5판 이상이면 표시합니다. 5~9판은 표본이 적으므로, 화면에 결과의 정확도가 낮을 수 있다는 안내를 함께 표시합니다. 기본 시즌 시작일은 해당 연도의 1월 8일 12:00(KR)이며, `.env`의 `SEASON_START=YYYY-MM-DD`로 조정할 수 있습니다.

첫 동기화는 매치 목록을 100게임 단위로 끝까지 조회하고, 각 게임 상세를 로컬 `data/riot-season-cache.json`에 저장합니다. Riot 개발 키의 요청 제한을 지키기 위해 게임 상세를 약 1.25초 간격으로 수집하므로 게임 수에 따라 시간이 오래 걸릴 수 있습니다. 이후 수동 새로고침은 이미 저장된 게임을 재조회하지 않고, 이번 시즌에 새로 추가된 게임만 가져옵니다.

## 로컬 저장 데이터

- `data/users.json`: 사용자 표시 이름, Riot ID, 태그, 기본 라인, 활성 상태, 마지막 동기화 시각
- `data/riot-season-cache.json`: 이번 시즌에 수집된 랭크 매치 상세

두 파일은 로컬 서버를 종료하거나 다시 시작해도 유지됩니다. 전체 시즌 수집 도중 서버가 꺼진 경우에도, 다음 사용자 선택 또는 수동 동기화 때 이미 저장된 매치 상세는 다시 조회하지 않습니다. `data/`는 Git에서 제외되어 있습니다.
