# Chamlog

개인용 League of Legends 챔피언 숙련도 분석 웹앱입니다. 사용자가 선택한 챔피언의 공식 숙련도와 최근 솔로랭크·자유랭크 전적을 분석합니다.

## 실행

```powershell
npm install
Copy-Item .env.example .env
```

`.env`의 `RIOT_API_KEY`에 [Riot Developer Portal](https://developer.riotgames.com/)에서 발급한 키를 입력한 다음 실행합니다.

```powershell
npm run dev
```

- 웹 화면: `http://localhost:5173`
- API 서버: `http://localhost:8787`

`RIOT_API_KEY`는 서버만 읽습니다. 키를 `VITE_` 환경 변수로 만들거나 Git에 커밋하면 안 됩니다.

## 개인용 상시 배포 (Render)

PC에서 `npm run dev`를 실행하지 않고 접속하려면 Render에 배포합니다. 저장 데이터가 유지되어야 하므로 무료·임시 파일 시스템 배포는 사용하지 않습니다.

1. GitHub에 현재 저장소를 비공개로 푸시합니다. `.env`와 `data/`는 포함하지 않습니다.
2. Render Dashboard에서 **New → Blueprint**를 선택하고 저장소를 연결합니다. 루트의 `render.yaml`을 사용합니다.
3. 생성 화면에서 `RIOT_API_KEY`와 긴 `APP_PASSWORD`를 입력합니다. `APP_USERNAME`은 기본값 `chamlog`를 쓰거나 변경할 수 있습니다.
4. 배포 완료 후 Render URL에 접속하여 브라우저의 Basic Auth 창에 사용자 이름과 비밀번호를 입력합니다.

`render.yaml`은 싱가포르 리전의 웹 서비스와 `/var/data` 영속 디스크를 구성합니다. 이 디스크에 사용자와 시즌 분석 캐시가 저장되므로 재배포 후에도 유지됩니다. Render의 영속 디스크는 유료 웹 서비스에 연결할 수 있습니다. Riot API는 개인·소규모 비공개 사용에 맞는 Personal API Key를 사용하고, 개발 키로 공개 서비스를 운영하지 마세요.

## 동기화 범위

저장된 사용자를 선택하면 Riot API를 호출하지 않고, 해당 계정의 마지막 분석 결과를 즉시 표시합니다. 마지막 동기화 시각을 확인한 뒤 사용자가 **데이터 새로고침**을 눌렀을 때만 새 게임을 수집·분석합니다.

- Riot ID와 태그를 통한 PUUID 조회
- KR 랭크 정보
- 공식 챔피언 숙련도
- 솔로랭크(420)와 자유랭크(440)의 이번 시즌 전체 매치 목록
- 이번 시즌 게임을 기반으로 한 챔피언별 개인 통계 및 AI 숙련도
- 챔피언·라인별 이번 시즌 최다 사용 룬 조합: 주/보조 룬 경로, 능력치 파편, 사용 게임 수·비율·해당 조합 승률(Riot Data Dragon 정적 데이터로 명칭 변환)

AI 숙련도는 역할별 핵심 지표 50%, 최근 승률 20%, 최근 플레이 빈도 15%, 플레이 횟수 10%, 비교 기준 5%의 내부 가중치를 사용합니다. 메타 티어와 카운터는 외부 데이터 수집 규정을 검토한 뒤 별도로 연동합니다.

역할별 핵심 지표는 탑·미드·원딜의 CS/분·골드/분·피해량/분, 정글의 초반 정글 CS·킬 관여·피해량/분, 서포터의 시야 점수/분·킬 관여·제어 와드 구매를 사용합니다. 동티어·동일 챔피언 평균 비교는 허용된 외부 비교 데이터가 준비되기 전까지 중립값으로 처리합니다.

AI 숙련도는 이번 시즌 분석 게임이 5판 이상이면 표시합니다. 5~9판은 표본이 적으므로, 화면에 결과의 정확도가 낮을 수 있다는 안내를 함께 표시합니다. 기본 시즌 시작일은 해당 연도의 1월 8일 12:00(KR)이며, `.env`의 `SEASON_START=YYYY-MM-DD`로 조정할 수 있습니다.

점수 등급은 80점 이상 `매우 숙련`, 65~79점 `안정적`, 50~64점 `보통`, 0~49점 `보완 필요`로 표시합니다. 5게임 미만은 `데이터 부족`, 5~9게임은 `표본 적음 · 등급`으로 표시합니다.

첫 동기화는 매치 목록을 100게임 단위로 끝까지 조회하고, 각 게임 상세를 로컬 `data/riot-season-cache.json`에 저장합니다. Riot 개발 키의 요청 제한을 지키기 위해 게임 상세를 약 1.25초 간격으로 수집하므로 게임 수에 따라 시간이 오래 걸릴 수 있습니다. 이후 수동 새로고침은 이미 저장된 게임을 재조회하지 않고, 이번 시즌에 새로 추가된 게임만 가져옵니다.

동기화 중에는 현재 수집 게임 수, 경과 시간, 예상 남은 시간을 표시합니다. `동기화 취소`를 누르면 현재 요청이 끝난 뒤 작업을 멈추며, 이미 저장한 매치 상세는 유지됩니다. 다음 사용자 선택 또는 동기화에서 저장하지 못한 게임만 이어서 수집합니다.

## 로컬 저장 데이터

- `data/users.json`: 사용자 표시 이름, Riot ID, 태그, 기본 라인, 활성 상태, PUUID, 마지막 동기화 시각
- `data/riot-season-cache.json`: 이번 시즌에 수집된 랭크 매치 상세와 PUUID별 마지막 분석 결과

두 파일은 로컬 서버를 종료하거나 다시 시작해도 유지됩니다. 전체 시즌 수집 도중 서버가 꺼진 경우에도, 다음 수동 동기화 때 이미 저장된 매치 상세는 다시 조회하지 않습니다. 페이지 새로고침과 사용자 선택은 PUUID별 저장 분석 결과만 읽으므로 Riot API를 호출하지 않습니다. 계정의 Riot ID 또는 태그를 바꾸면 이전 PUUID 연결을 해제하며, 새 계정에는 수동 첫 동기화가 필요합니다. `data/`는 Git에서 제외되어 있습니다.
